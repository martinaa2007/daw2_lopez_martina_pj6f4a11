Description and documentation

About the application

Sweet Bakes Orders is an order management application for our sales team. After logging in, salespeople can create new customer orders and look up the orders that have already been saved.

Operations menu

Create a new order

Fill in the form with the order code, the customer's full name, address, email and phone number. Then tick the checkbox next to each product the customer wants and enter the quantity. When you send the form, the application shows the price of the order including 21% VAT, and the order is saved automatically.

View orders

This option has two operations:

View all orders: shows all the saved orders in a table.

View one order: enter the code of an order and the application shows all its data in a table.

If the order code does not exist, or the orders file cannot be found, an error message is shown.
